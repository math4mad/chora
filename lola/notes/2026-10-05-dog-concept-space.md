### 贝叶斯视角下的正确顺序

你提到的“如果是贝叶斯，遇到大字当头，应该首先把所有长安镇的信息切除掉”——这句话揭示了一个关键原则：

**约束是硬性条件（硬剪枝），先验是软性偏好（加权）。约束必须先在先验起作用之前执行。**

正确逻辑：

```
P(镇 | 东莞, 大字, 图书馆) ∝ P(镇 | 东莞) · I[镇 满足 "大字" 约束] · I[镇 满足 "图书馆" 约束]
                              ↑先验          ↑硬约束（0/1 门控）
```

- **先验** `P(镇|东莞)`：长安镇最高（高频）
- **硬约束** `I[满足大字]`：长安镇 = 0（“长”不含“大”），大朗/大岭山 = 1

**乘法顺序决定了：`P(长安) = 高频 × 0 = 0`**。约束一乘进去，长安镇直接被清零，不管它先验多高。

这就是你说的“**联合概率分布 = 镇 × 带大字 × 图书馆**”——三者相乘，任一为 0 则整体为 0。

### 为什么会推到长安镇（失败模式）

失败的原因，几乎可以肯定是**约束没有被当作硬门控，而是被当作软性加权（或根本没应用）**。三种可能的错误：

| 错误 | 表现 |
| --- | --- |
| 先验主导，约束后置 | 先按高频选出长安镇，再查约束——但此时可能已经“锁定”长安镇 |
| 约束当软加权 | P ∝ 先验 × 0.9^(不符合) 而非 × 0——长安镇仍有残留概率 |
| 约束根本没解析 | “大字”没被识别为约束，系统只看到“东莞+镇”→ 长安镇自然胜出 |

**你的论断正确**：正确贝叶斯下，“大字”当头，长安镇的信息**应该被先切除**——不是靠降低权重，而是**直接置 0（硬剪枝）**。

### 一个更精确的数学表述

你说的“联合概率分布 = 镇 × 带大字 × 图书馆”其实是一个**硬门控贝叶斯**：

```
P(x | 东莞, 大字, 图书馆) = 
    P(x | 东莞)      # 先验：镇在东莞的频率分布（长安镇高）
  × g_大字(x)         # 硬门控：0 若不满足"大字", 1 若满足
  × g_图书馆(x)       # 硬门控：0 若不满足"图书馆", 1 若满足
```

**这就是你一直在讲的“一个除法”的完整形态**——贝叶斯后验的分子是“先验 × 似然”，而这里的“似然”就是硬门控（约束是否满足）。长安镇因为 `g_大字 = 0`，整项归零。

    joint = {t: (prob[t] if t in survivors else 0.0) for t in pool}
    return survivors, prob, joint

## 如何把符号约束推理接入小模型 / 大模型

### 先定位：你的推理在这张图里的位置

你的“镇×大字×图书馆，先硬剪枝后先验”本质是一个**确定性的符号推理器（symbolic reasoner）**。神经网络模型（无论大小）的角色，应该是**端到端语言理解 + 约束生成**，而**约束应用交给符号引擎保证正确性**。这是当前神经符号集成的主流范式。

```
┌─────────────────────────────────────────────┐
│  神经网络（LLM 或 SLM）                       │
│  任务1: 把自然语言提示词解析成结构化约束       │
│    "广东 镇 大字 图书馆" → {省:广东, 层:镇,   │
│                            字首:大, 设施:图书馆}│
│  任务2: 生成候选/排序（软先验）                │
└──────────────┬──────────────────────────────┘
               ▼
┌─────────────────────────────────────────────┐
│  你的符号引擎（保证正确性）                   │
│  阶段一: 硬剪枝（约束门控）→ 长安镇被置0       │
│  阶段二: 先验归一化（幸存者之间）              │
│  输出: {大朗 53%, 大岭山 47%}                │
└─────────────────────────────────────────────┘
```

**核心分工**：神经网络负责**灵活的理解与生成**，你的符号引擎负责**硬约束的正确性**——这正对应文献里的“LLM proposes, symbolic verifies”。

---

### 接入方式：三档（从轻到重）

#### 档位 A：约束解码（最直接，零训练）

**思想**：不改变模型，只在**解码时**把违反约束的 token 概率置为 0/-∞。这就是你的“硬剪枝”在 token 层的实现。

```
生成时，模型想输出"长安镇"：
  token 级约束: "长安"的首字不是"大" → 首字"长"的 logit = -∞
  → 模型根本无法生成"长安镇"
```

- **优点**：零训练、即插即用、保证约束
- **缺点**：文献指出严格约束可能损害 LLM 的自由推理能力——但你的场景（地名候选有限）正适合

**你的算法如何映射**：

- 你的 `features(town)` 知识库 → 构造成**前缀树（prefix tree/trie）**，叶子是合法镇名
- 解码时只允许走合法路径 → 长安镇（首字非“大”）被天然屏蔽

#### 档位 B：LLM 提出 / 符号验证（推荐，无需重训）

**思想**：LLM 负责**解析约束 + 生成候选**（利用它的语言理解和世界知识），你的符号引擎**验证并纠正**。

```
循环:
  1. LLM 解析提示词 → 结构化约束 {镇, 大字, 图书馆}
  2. 你的引擎: 硬剪枝 → {大朗, 大岭山}（长安被切）
  3. LLM 在幸存者里生成/排序（软先验）
  4. 若 LLM 输出长安镇 → 引擎发现 长安 ∉ 幸存集 → 强制纠正/重新生成
```

**这正是你测试失败场景的修复**：如果 LLM 因高频先验“跳到长安镇”，符号引擎发现长安镇不满足“大字”约束，**回退纠正**。这对应文献中的自检/回退机制。

#### 档位 C：训练对齐（SLM 微调 / 大模型 RLHF）

**思想**：把“先硬剪枝后先验”的推理顺序**变成模型的偏好**。

- **小模型（SLM）**：用 LLM 生成的合成演示做指令微调，再偏好优化，让 SLM 学会“约束先于先验”
- **大模型**：把符号引擎的验证结果作为可验证奖励，做 **RL / DPO**，让模型内化“长安镇在‘大字’约束下必须被排除”

**优点**：模型学会自主应用约束，减少对符号引擎的每次调用

**缺点**：成本高，且仍需符号引擎兜底保证正确性

### 推荐架构：分层神经符号（最适合你的场景）

```
┌────────────────────────────────────────────┐
│  小模型 SLM（廉价，在线部署）                 │
│  - 解析提示词 → 约束                          │

```

**为什么这样分**：

- **小模型**处理 90% 的常规解析（成本低）

- **大模型**只在歧义时介入（避免不必要的成本）

这符合“small model + symbolic grounding”的实证优势，以及“symbolics constrain, LLM generates”的范式。

## Dog 概念空间：有限集合版算法骨架

```
python"""
Dog 概念空间 —— 有限集合版
=================================================
关键假设：概念空间的支撑集是有限的、可枚举的，总规模 ≤ 10万级
        （如 WordNet 名词概念 ≈ 8万 个）

推论：先验 = 有限表 + 计数，而非概率密度
      CRP/高斯/DP 只在"真·集合外出现新值"(黑天鹅)时才需要
"""

class FiniteConceptSpace:
    """
    有限概念空间：
    - 每个概念的取值空间是预先枚举的有限集合
    - 先验 = {值: 计数} 稀疏字典
    - 在线增量贝叶斯：今天的后验 = 明天的先验
    """

    def __init__(self, dims, universe_size_hint=100_000):
        """
        dims: {维度名: 有限取值集}
        例如 Dog 概念空间：
          dims = {
            "品种": {金毛, 柯基, 边牧, 中华田园犬, ...},   # 有限几百种
            "大小": {小型, 中型, 大型, 巨型},             # 有限几个档
            "颜色": {黑, 白, 黄, 棕, 花, ...},           # 有限几十种
            "智力": {低, 中, 高},                         # 有限
            "忠诚度": {低, 中, 高},                       # 有限
          }
        """
        self.dims = dims
        # 每个维度的先验: {值: 出现次数} (稀疏, 只存见过的)
        self.counts = {name: {} for name in dims}
        # 全局未见过集合 (黑天鹅留名表)
        self.black_swan = {}   # 维度名 -> 没见过但出现过的值

    # ====================================================
    # 1. 观测注入: 在线增量更新 (今天的后验 = 明天的先验)
    # ====================================================
    def observe(self, dim, value, weight=1.0):
        """
        看到一个观测值:
        - 若在有限支撑集内 → 计数 +1 (查表, O(1))
        - 若在支撑集外 (黑天鹅) → 进 black_swan 留名 (CRP 式)
        """
        if value in self.dims[dim]:
            self.counts[dim][value] = self.counts[dim].get(value, 0) + weight
        else:
            # 黑天鹅: 先验里没有, 但出现了 → 留名
            self.black_swan.setdefault(dim, {})
            self.black_swan[dim][value] = self.black_swan[dim].get(value, 0) + weight

    # ====================================================
    # 2. 推理: 先验归一化 (有限表直接除)
    # ====================================================
    def prior(self, dim, value):
        """P(值) = n_k / (N + α), 一个除法"""
        N = sum(self.counts[dim].values())
        n = self.counts[dim].get(value, 0)
        alpha = 1.0   # 平滑
        return (n + alpha) / (N + alpha * len(self.dims[dim]))

    def predict(self, dim):
        """对某维度做预测: 归一化后取最可能值"""
        total = sum(self.prior(dim, v) for v in self.dims[dim])
        probs = {v: self.prior(dim, v)/total for v in self.dims[dim]}
        return probs

    # ====================================================
    # 3. 整体概念联合概率 (各维度独立乘积)
    # ====================================================
    def joint(self, assignment):
        """P(大小, 品种, 颜色...) = Π P(维度|值)"""
        p = 1.0
        for dim, value in assignment.items():
            p *= self.prior(dim, value)
        return p

# ============================================================
# 实例化: Dog 概念空间 (有限支撑集)
# ============================================================
dog_space = FiniteConceptSpace({
    "品种": ["金毛", "柯基", "边牧", "中华田园犬", "萨摩耶", "哈士奇", "德牧", "泰迪", "柴犬", "拉布拉多"],
    "大小": ["小型", "中型", "大型", "巨型"],
    "颜色": ["黑色", "白色", "黄色", "棕色", "花色", "灰色"],
    "智力": ["低", "中", "高"],
    "忠诚度": ["低", "中", "高"],
})

# 注入观测 (语料频率)
dog_space.observe("品种", "金毛", 150)
dog_space.observe("品种", "柯基", 120)
dog_space.observe("品种", "边牧", 90)
dog_space.observe("品种", "中华田园犬", 80)
dog_space.observe("品种", "萨摩耶", 60)
dog_space.observe("品种", "哈士奇", 50)
dog_space.observe("品种", "泰迪", 45)
dog_space.observe("品种", "柴犬", 40)
dog_space.observe("品种", "德牧", 30)
dog_space.observe("品种", "拉布拉多", 25)

# 黑天鹅: 出现了一个支撑集外的罕见品种
dog_space.observe("品种", "藏獒", 5)

# 推理
print("品种先验 (归一化后):")
probs = dog_space.predict("品种")
for v, p in sorted(probs.items(), key=lambda x: -x[1])[:5]:
    print(f"   {v:<6s} {p:.1%}")

print()
print(f"黑天鹅留名表: {dog_space.black_swan}")
print(f"  → 藏獒不在有限支撑集里, 但出现了 → CRP 式留名, 下次可进支撑集")

# 联合概率: 一只"金毛, 大型, 黄色, 高智力, 高忠诚"的狗
p = dog_space.joint({"品种": "金毛", "大小": "大型", "颜色": "黄色", "智力": "高", "忠诚度": "高"})
print(f"\n典型狗联合概率: {p:.4e}")

## Dog 概念空间：固定先验 × 无限后验（最小完整版）

```
pythonimport numpy as np
from collections import defaultdict

# ============================================================
# 核心洞察
#   概念取值有限 (输出空间可枚举) → 先验是固定的一张表, 可查表
#   但"观测→取值"的映射有不确定性 → 后验随观测连续变化, 无限多样
#   → 需要概率密度 (高斯软映射) 把连续观测变成有限取值上的软隶属度
#
#   "固定先验" 解决: 黑天鹅留名、可审计、可在线更新
#   "无限后验" 解决: 输入不确定性、连续观测、模糊描述
# ============================================================

# ============================================================
# 1. 显式先验层: 固定、有限、可审计
#    来源: 语料频率 (这正是大模型缺失的"显式概念表")
# ============================================================

class ExplicitPrior:
    """固定先验表: 每个维度 → 有限取值 → 固定频率 (一个除法)"""

    def __init__(self, dims):
        """
        dims: {维度名: {取值: 先验频数}}
        """
        self.dims = dims
        # 每个维度的总计数 (固定先验时不变)
        self.totals = {d: sum(c.values()) for d, c in dims.items()}

    def prior(self, dim, value):
        """P(值) = n / N   (固定, 一个除法)"""
        n = self.dims[dim].get(value, 0)
        return n / self.totals[dim] if self.totals[dim] else 0.0

    def audit(self):
        """可审计: 直接看先验表 (大模型做不到)"""
        for d in self.dims:
            top = sorted(self.dims[d].items(), key=lambda x: -x[1])[:3]
            print(f"   {d}: " + ", ".join(f"{k}={v}" for k, v in top))

# Dog 概念的显式先验表 (固定, 来自语料频率)
dog_prior = ExplicitPrior({
    "品种": {"金毛": 150, "柯基": 120, "边牧": 90, "中华田园犬": 80,
             "萨摩耶": 60, "哈士奇": 50, "泰迪": 45, "柴犬": 40,
             "德牧": 30, "拉布拉多": 25},
    "大小": {"小型": 100, "中型": 150, "大型": 120, "巨型": 40},
    "颜色": {"黑色": 90, "白色": 80, "黄色": 70, "棕色": 60,
             "花色": 40, "灰色": 20},
    "智力": {"低": 50, "中": 80, "高": 120},
    "忠诚度": {"低": 40, "中": 90, "高": 120},
})

# ============================================================
# 2. 高斯软映射层: 把连续/不确定观测 → 有限取值上的软隶属度
#    这一层就是"输入不确定性需要概率密度"的位置
# ============================================================

def gaussian(x, mu, sigma):
    """高斯密度"""
    return np.exp(-0.5 * ((x - mu) / sigma) ** 2) / (sigma * np.sqrt(2 * np.pi))

class GaussianSoftMapper:
    """
    把连续观测 (如身高62cm) 映射到有限档位 (小型/中型/大型) 上的软隶属度
    P(取值 | 观测) = 该取值的中心高斯密度 / 所有取值密度之和
    """

    def __init__(self, centers, sigmas):
        """
        centers: {取值: 连续轴中心}  如 {"小型":30, "中型":55, "大型":70, "巨型":85}
        sigmas:  {取值: 高斯宽度} (观测不确定性的来源)
        """
        self.centers = centers
        self.sigmas = sigmas

    def map(self, x):
        """连续观测 x → {取值: 软隶属度}"""
        dens = {v: gaussian(x, mu, self.sigmas[v])
                for v, mu in self.centers.items()}
        z = sum(dens.values()) or 1.0
        return {v: d / z for v, d in dens.items()}

# 大小: 连续身高(cm) → 有限档位的软映射
size_mapper = GaussianSoftMapper(
    {"小型": 30, "中型": 55, "大型": 70, "巨型": 85},
    {"小型": 10, "中型": 12, "大型": 12, "巨型": 12},
)

# ============================================================
# 3. 后验层: 无限多样, 随观测连续更新
#    今天的后验 = 明天的先验 (在线增量贝叶斯)
#    用软隶属度作为分数计数注入
# ============================================================

class Posterior:
    """后验: 在固定先验基础上, 用软观测分数更新计数"""

    def __init__(self, explicit_prior):
        self.prior = explicit_prior
        # 后验计数 = 先验计数 + 观测注入 (从固定先验出发)
        self.counts = {d: dict(c) for d, c in explicit_prior.dims.items()}
        self.black_swan = defaultdict(lambda: defaultdict(float))  # 黑天鹅留名

    def observe_soft(self, dim, soft, weight=1.0):
        """
        注入一个软观测 {取值: 隶属度}:
        - 在支撑集内 → 分数计数注入 (高斯软映射的产物)
        - 支撑集外 (黑天鹅) → CRP 式留名
        """
        for value, membership in soft.items():
            if value in self.counts[dim]:
                self.counts[dim][value] += membership * weight
            else:
                # 黑天鹅: 先验里没有但出现了 → 留名
                self.black_swan[dim][value] += membership * weight

    def observe_hard(self, dim, value, weight=1.0):
        """硬观测: 已知确切取值 (如"金毛")"""
        if value in self.counts[dim]:
            self.counts[dim][value] += weight
        else:
            self.black_swan[dim][value] += weight

    def posterior(self, dim, value):
        """P(值|观测) = (先验频数 + 后验注入) / 总计数  —— 一个除法"""
        total = sum(self.counts[dim].values())
        return self.counts[dim][value] / total if total else 0.0

    def predict(self, dim):
        total = sum(self.counts[dim].values())
        return {v: c / total for v, c in self.counts[dim].items()}

# ============================================================
# 4. 演示: 固定先验如何变成无限多样的后验
# ============================================================

post = Posterior(dog_prior)

print("=" * 70)
print("第一步: 固定先验 (来自语料频率, 可审计)")
print("=" * 70)

print("=" * 70)

    # 注入
    post.observe_soft("大小", soft)

print("\n" + "=" * 70)
print("第三步: 同一个固定先验 → 无限多样的后验")
print("=" * 70)

postA = Posterior(dog_prior); postB = Posterior(dog_prior); postC = Posterior(dog_prior)

# 观测 A: 一只精确的"金毛, 大型"
postA.observe_hard("品种", "金毛", 5)
postA.observe_soft("大小", size_mapper.map(68))
# 观测 B: 一只模糊的"中等偏大的黄狗"
postB.observe_hard("品种", "金毛", 1)
postB.observe_soft("大小", size_mapper.map(60))
# 观测 C: 一只罕见的"藏獒" (黑天鹅!)
postC.observe_hard("品种", "藏獒", 3)  # 不在支撑集里 → CRP 留名

print("\n后验 A (5只精确金毛大型):")
print(f"   P(品种=金毛|A) = {postA.posterior('品种','金毛'):.1%}   (先验原本 {dog_prior.prior('品种','金毛'):.1%})")
pa = postA.predict("大小")
print(f"   大小后验: " + ", ".join(f"{v}={p:.0%}" for v,p in sorted(pa.items(), key=lambda k:-k[1])[:2]))

print("\n后验 B (1只模糊中等偏大):")
print(f"   P(品种=金毛|B) = {postB.posterior('品种','金毛'):.1%}   (先验原本 {dog_prior.prior('品种','金毛'):.1%})")
pb = postB.predict("大小")
print(f"   大小后验: " + ", ".join(f"{v}={p:.0%}" for v,p in sorted(pb.items(), key=lambda k:-k[1])[:2]))

print(f"   品种后验: " + ", ".join(f"{v}={p:.1%}" for v,p in sorted(postC.predict('品种').items(), key=lambda k:-k[1])[:3]))
print(f"   黑天鹅留名表: dict({ {k:dict(v) for k,v in postC.black_swan.items()} })")
print(f"   → 藏獒不在固定先验里, 但出现了 → CRP 留名, 下次可进先验")

print("=" * 70)
print("先验是固定的底图 (有限可枚举, 可审计)")

## DP-mixture 加进“大小”维度：动态开新分量

```
pythonimport numpy as np
from collections import defaultdict

# ============================================================
# 目标: 把 DP-mixture 真正加进"大小"维度
#
# 之前: "大小"是固定档位 {小型/中型/大型/巨型}, 高斯软映射
# 现在: "大小"是连续身高, 观测可能形成先验中没有的新身高中心
#      → DP-mixture 用中国餐馆过程(CRP)动态开新分量
#
# 关键: 概念取值有限 ≠ 每个维度的观测中心固定
#      "大小"的真实中心(身高分布峰) 是未知的、可能随数据增长
#      DP-mixture 自动发现: 新身高密集区 → 开新高斯分量
# ============================================================

# ============================================================
# 1. 高斯分量 (每个"大小簇" = 一个高斯: 均值+方差)
# ============================================================

class GaussianComponent:
    """一个高斯分量: 代表一个"大小簇"(身高中心)"""

    def __init__(self, mu, sigma_sq):
        self.mu = mu          # 身高中心
        self.sigma_sq = sigma_sq  # 方差
        self.n = 0            # 该簇的观测数

    def log_density(self, x):
        """高斯对数密度"""
        return -0.5 * (np.log(2*np.pi*self.sigma_sq)
                       + (x - self.mu)**2 / self.sigma_sq)

    def update(self, x, weight=1.0):
        """吸收一个观测 (更新均值/方差, 一个贝叶斯增量)"""
        new_n = self.n + weight
        # 在线更新均值 (Welford 式)
        delta = x - self.mu
        self.mu += delta * weight / new_n
        # 在线更新方差 (近似)
        self.sigma_sq = ((self.n) * self.sigma_sq
                         + weight * (x - self.mu)**2) / new_n
        self.n = new_n

    def __repr__(self):
        return f"G(mu={self.mu:.0f}, var={self.sigma_sq:.1f}, n={self.n:.0f})"

# ============================================================
# 2. DP-mixture 分量管理器 (中国餐馆过程: 开新桌)
# ============================================================

class DPMMSizeDimension:
    """
    "大小"维度的 DP-mixture:
    - 已发现的身高中心 → 高斯分量 (可复用, 概率 ∝ n_k)
    - 新高身高 → 开新分量 (概率 ∝ α)
    - 这就是"连续维度开新分量", 不同于离散维度的 CRP 类别
    """

    def __init__(self, alpha=1.0, base_mu=70, base_sigma_sq=100):
        self.alpha = alpha          # 浓度参数: 越大越容易开新分量
        self.components = []        # 已发现的分量列表
        self.base_mu = base_mu      # 新分量的先验均值 (base measure G0)
        self.base_sigma_sq = base_sigma_sq

    def _open_new(self, x):
        """开新分量: 从 base measure 抽参数, 以 x 为初始中心"""
        # 新分量中心 = 观测本身 (贴近数据), 方差 = base 方差
        comp = GaussianComponent(mu=x, sigma_sq=self.base_sigma_sq)
        self.components.append(comp)
        return comp

    def observe(self, x, weight=1.0):
        """
        注入一个连续身高观测 x:
        - 以 ∝ n_k/(N-1+α) 加入已有分量 (数据密集处复用)
        - 以 ∝ α/(N-1+α) 开新分量 (新身高密集区)
        这是"开新分量"的核心决策
        """
        N = sum(c.n for c in self.components)

        # 计算每个已有分量的加入概率 + 开新分量概率
        scores = []
        for c in self.components:
            # ∝ 已有观测数 + 高斯似然 (软分配)
            scores.append(c.n + weight * np.exp(c.log_density(x)))
        # 开新分量 ∝ α
        scores.append(self.alpha)

        # 归一化成概率
        total = sum(scores)
        probs = [s/total for s in scores]

        # 采样/选择: 落在哪个分量
        choice = np.random.choice(len(scores), p=probs)
        if choice == len(self.components):
            # 选到了"新桌" → 开新分量
            comp = self._open_new(x)
            comp.update(x, weight)
            opened = True
        else:
            comp = self.components[choice]
            comp.update(x, weight)
            opened = False
        return comp, opened

    def predict_density(self, x):
        """在新观测 x 处, DP 混合的预测密度 = Σ (权重 × 高斯密度)"""
        total_w = sum(c.n for c in self.components) + self.alpha
        return sum(
            (c.n / total_w) * np.exp(c.log_density(x))
            for c in self.components
        ) + (self.alpha / total_w) * np.exp(
            -0.5*((x - self.base_mu)**2)/self.base_sigma_sq
        ) / np.sqrt(2*np.pi*self.base_sigma_sq)

    def summary(self):
        print(f"   已发现分量数: {len(self.components)}")
        for c in self.components:
            print(f"   {c}")

## WordNet 对构建概念空间先验的真实帮助

先明确结论：**有帮助，但不是全部。它主要帮你搭「概念骨架」和「离散先验」，帮不上「连续先验」和「后验」。** 我按能帮/帮不上拆开讲。

### 一、WordNet 是什么（数据层面）

- **规模**：155,287 个词、117,659 个 synset、206,941 个词义对。其中名词 117,798 词 / 82,115 个 synset
- **synset** = 一组同义词，代表一个概念（如 {night, nighttime, dark} 是一个 synset）
- **每个 synset 带 gloss**（自然语言定义）+ 例句
- **层次结构**：通过上位词/下位词（is-a 关系）组织成树，如 car → motor_vehicle → wheeled_vehicle → … → entity
- **其他关系**：part-of（整体部分）、is-made-of（物质构成）等
- **多语种**：不止英语，全球有很多 WordNet（Open Multilingual WordNet）

这些数据里，对你的概念空间先验**有直接价值**的：

### 二、能帮上的 4 件事

**1. 枚举「概念空间」的取值候选（你已验证过的那条线）**

这是最直接的一环。你要的「输出空间可枚举、总数 ≤10 万」，WordNet 就是候选来源之一：名词 8.2 万 synset ≈ 8.2 万概念节点，正好落在你之前判断的「≤10 万」区间。它提供的是**离散概念的候选全集**，可以灌进你的 `ExplicitPrior` 有限先验表。

**2. 提供「先验结构」——不只是平铺的取值表，而是层次**

WordNet 的 is-a 树给了你**概念之间的上下位关系**。这对先验的意义很大：你的先验不该是一张「平铺的 8 万取值表」，而应是一棵带继承的树。比如「狗」是「犬科」的下位、「犬科」是「哺乳动物」的下位。先验概率可以在树上传播（父节点承接子节点），这比平铺表更有信息量。

**3. 提供「语义定义」（gloss）→ 作为观测→概念的映射锚点**

每个 synset 的 gloss 是自然语言定义。这能帮你把**观测文本 → 概念**的映射做实：一个描述「大型犬，毛茸茸，爱叫」的观测，能通过 gloss 里的词命中「狗.n.01」这个 synset。这是 `GaussianSoftMapper` 之外的另一种软映射锚点。

**4. 提供「词义频率」作为频率先验的种子**

WordNet 标注了每个词义的相对频率（reference corpus 中的出现次数）。这正好可以给你的「频率先验」当种子——`ExplicitPrior` 里每个概念的先验概率，不必全手工设定，可以直接用 WordNet 的词义频率初始化。

### 三、帮不上的 3 件事（关键边界）

**1. 连续属性（大小）的先验——WordNet 完全没有**

WordNet 是**词汇-概念**数据库，只编码「是什么」（is-a）关系。它不编码「身高 30cm vs 85cm 的概率分布」。你刚做的 DP-mixture「大小」维度，WordNet 帮不上——这正是为什么你需要 `GaussianSoftMapper` + DP-mixture 自己建模连续维度。**WordNet 管「有哪些概念」，不管「连续属性怎么分布」。**

**2. 后验——WordNet 全是先验，没有后验**

WordNet 是静态的、编纂好的词库，代表「一个语言社区共享的先验结构」。它不含、也不该含「某个特定用户/场景下观测堆积出来的后验」。你的架构里「今天后验=明天先验」的增量过程，WordNet 管不了——它是**先验的来源**，不是**后验的容器**。

**3. 常识性软约束（地理、物理规律）——WordNet 只有词间关系**

你之前做的「东莞 28 镇」「直筒子市」「长安镇结构性不可采样」这类地理/常识约束，WordNet 里没有。它是语言本体，不是常识知识库。这类硬约束需要别的资源（如 GeoNLP、GeoNames、常识知识库 ConceptNet）或你手工编码。

### 四、给你的定位建议

把 WordNet 放进你架构里，它的位置是**「离散概念层的先验骨架来源」**：

```
概念空间先验 = WordNet(离散概念+层次+gloss+词义频率)
             + 你自己编码的连续属性先验(大小→高斯)
             + 你手工编码的硬约束(地理/常识)
后验        = 观测注入, DP-mixture 动态开新分量
```

WordNet 解决的是你「有限先验表」里**离散那半**的实际数据来源——给你 8 万概念的候选全集、层次结构和频率种子。但它**填补不了连续属性先验、后验、和常识硬约束**这三块，那些仍是架构里需要你自己建模的部分。

# ============================================================
# 目标: 把 WordNet 的 is-a 树真正接入 ExplicitPrior
#
# 之前: ExplicitPrior = 平铺查表 (固定先验表, 8万项)
# 现在: 先验 = 概念树 + 每节点传播概率
#       - 只需给 根/上层节点 显式设先验
#       - 下层节点概率 = 沿 is-a 路径累乘传播因子
#       - 从 8万平铺表 → 压缩为 树结构 + 少量根先验
#
# 对应 WordNet 事实:
#   - synset 经 is-a(上下位) 组成树 [5](@index-ref?id=5)[1](@index-ref?id=6)
#   - 子节点是父节点的下位, 所有子实例都是父实例 [1](@index-ref?id=7)
#   - 名词空间 82,115 节点可抽成树, 节点即假设 [4](@index-ref?id=8)
# ============================================================

class WordNetConceptNode:
    """概念树上的一个节点 = 一个 synset"""

    def __init__(self, synset_id, name):
        self.synset_id = synset_id   # e.g. "dog.n.01"
        self.name = name
        self.children = []           # 下位词 (hyponyms)
        self.parent = None
        self._prior_set = None       # 显式设置的先验 (只在根/上层)

    def add_child(self, child):
        self.children.append(child)
        child.parent = self

# ============================================================
# 先验: 树结构 + 传播规则 (不是平铺表!)
# ============================================================

class TreePrior:
    """
    概念树先验:
    - 只在根节点显式设先验 P(root)
    - 每个父节点带"子节点分摊比例" (children_weight, 归一化后=传播因子)
    - 任意下层节点的先验 = 从根沿路径累乘传播因子
    - 这就是"沿上下位传播", 而非平铺查表
    """

    def __init__(self, root_prior=0.5, spill=0.1):
        self.roots = []
        self.root_prior = root_prior   # 根概念总先验
        self.spill = spill             # 落到"其他/未列出"的残余概率

    def register_root(self, node, weight):
        """注册根节点 + 它的先验权重"""
        self.roots.append((node, weight))

    def _propagate(self, node, acc_prob, path):
        """
        沿 is-a 树传播概率:
        - acc_prob = 父节点累乘到当前的先验
        - 对每个子节点, 按 children_weight 分摊
        返回 {synset_id: 先验概率} (该子树的所有节点)
        """
        result = {node.synset_id: acc_prob}

        # 该节点的子节点权重
        total = sum(cw for _, cw in node.children)
        if total == 0:
            return result  # 叶子, 概率不再往下传

        # 每个子节点按权重分摊父节点概率
        for child, cw in node.children:
            child_prob = acc_prob * (cw / total)
            result.update(self._propagate(child, child_prob, path + [child.name]))
        return result

    def build_full_prior(self):
        """把整棵树摊平成 {synset_id: prior} 查表 (但来源是传播!)"""
        full = {}
        for root, w in self.roots:
            root_prob = self.root_prior * (w / sum(rw for _, rw in self.roots))
            full.update(self._propagate(root, root_prob, [root.name]))
        return full

    def prior(self, synset_id):
        """查询某概念的先验 (沿路径传播得到)"""
        return self.build_full_prior().get(synset_id, self.spill)

# ============================================================
# 构建一个真实的 WordNet 式 is-a 树: 犬科 → 狗 → 品种
# ============================================================

def build_canine_tree():
    """
    模拟 WordNet is-a 子树:
    entity(根) → mammal → canine → dog → {chihuahua, labrador, ...}

    两阶段推理：先硬剪枝（约束），后先验排序（高频）
    关键：约束必须先执行，把不满足的（如长安镇）直接切除，再让先验在幸存者里排序

    candidates = [self.root]
    for level in hierarchy_order:
        # ===== 阶段一：硬剪枝（约束门控）=====
        # 所有提示词约束是 0/1 硬条件，不满足的直接切除
        # 长安镇：不满足"大字" → 此处被置 0，无论它先验多高
        candidates = [c for c in candidates
                      if all(t in features(c) for t in prompt_terms)]

        # ===== 阶段二（仅目标层）：先验排序 =====
        # 在幸存者里（大朗、大岭山...），用先验频率排序/加权
        if level == target_level:
            return sorted(candidates, key=lambda c: prior_freq(c), reverse=True)
        # 下钻
        candidates = [child for c in candidates for child in tree(c)]

**顺序保障**：`阶段一`（硬剪枝）永远在 `阶段二`（先验）之前。长安镇先被“大字”切除，根本到不了先验排序那一步。

### 一个更精确的数学表述

### 关键结论（直接回应你的问题）

**为什么当时测试会推到长安镇？** 几乎可以确定是因为**推理顺序错了**：

|  | 正确（两阶段） | 错误（先验主导） |
| --- | --- | --- |
| 阶段一 | 先硬剪枝：大字把长安切除 | 先按频率选长安 |
| 阶段二 | 幸存者里按先验排序 | 再查约束（或没查） |
| 长安镇结果 | 概率 = 0（被切除） | 高概率胜出 |
| 最终候选 | {大朗镇, 大岭山镇} | 长安镇 |

**你的论断完全正确**：贝叶斯联合概率 `P ∝ 先验 × g_大字 × g_图书馆`，其中约束是 **0/1 硬门控**。长安镇 `g_大字 = 0`，整个联合概率直接归零——**遇到“大字”当头，首先就要把长安镇的信息切除**，这不是靠降权，而是硬置 0。

这也正是你说的“**联合概率分布 = 镇 × 大字 × 图书馆**”的精确含义：三者相乘，任一为 0 整体为 0。

## 如何把符号约束推理接入小模型 / 大模型

### 先定位：你的推理在这张图里的位置

你的“镇×大字×图书馆，先硬剪枝后先验”本质是一个**确定性的符号推理器（symbolic reasoner）**。神经网络模型（无论大小）的角色，应该是**端到端语言理解 + 约束生成**，而**约束应用交给符号引擎保证正确性**。这是当前神经符号集成的主流范式。

```
┌─────────────────────────────────────────────┐
│  神经网络（LLM 或 SLM）                       │
│  任务1: 把自然语言提示词解析成结构化约束       │
│    "广东 镇 大字 图书馆" → {省:广东, 层:镇,   │
│                            字首:大, 设施:图书馆}│
│  任务2: 生成候选/排序（软先验）                │
└──────────────┬──────────────────────────────┘
               ▼
┌─────────────────────────────────────────────┐
│  你的符号引擎（保证正确性）                   │
│  阶段一: 硬剪枝（约束门控）→ 长安镇被置0       │
│  阶段二: 先验归一化（幸存者之间）              │
│  输出: {大朗 53%, 大岭山 47%}                │
└─────────────────────────────────────────────┘
```

**核心分工**：神经网络负责**灵活的理解与生成**，你的符号引擎负责**硬约束的正确性**——这正对应文献里的“LLM proposes, symbolic verifies”。

---

### 接入方式：三档（从轻到重）

#### 档位 A：约束解码（最直接，零训练）

**思想**：不改变模型，只在**解码时**把违反约束的 token 概率置为 0/-∞。这就是你的“硬剪枝”在 token 层的实现。

```
生成时，模型想输出"长安镇"：
  token 级约束: "长安"的首字不是"大" → 首字"长"的 logit = -∞
  → 模型根本无法生成"长安镇"
```

- **优点**：零训练、即插即用、保证约束
- **缺点**：文献指出严格约束可能损害 LLM 的自由推理能力——但你的场景（地名候选有限）正适合

**你的算法如何映射**：

- 你的 `features(town)` 知识库 → 构造成**前缀树（prefix tree/trie）**，叶子是合法镇名
- 解码时只允许走合法路径 → 长安镇（首字非“大”）被天然屏蔽

#### 档位 B：LLM 提出 / 符号验证（推荐，无需重训）

**思想**：LLM 负责**解析约束 + 生成候选**（利用它的语言理解和世界知识），你的符号引擎**验证并纠正**。

```
循环:
  1. LLM 解析提示词 → 结构化约束 {镇, 大字, 图书馆}
  2. 你的引擎: 硬剪枝 → {大朗, 大岭山}（长安被切）
  3. LLM 在幸存者里生成/排序（软先验）
  4. 若 LLM 输出长安镇 → 引擎发现 长安 ∉ 幸存集 → 强制纠正/重新生成
```

**这正是你测试失败场景的修复**：如果 LLM 因高频先验“跳到长安镇”，符号引擎发现长安镇不满足“大字”约束，**回退纠正**。这对应文献中的自检/回退机制。

#### 档位 C：训练对齐（SLM 微调 / 大模型 RLHF）

**思想**：把“先硬剪枝后先验”的推理顺序**变成模型的偏好**。

- **小模型（SLM）**：用 LLM 生成的合成演示做指令微调，再偏好优化，让 SLM 学会“约束先于先验”
- **大模型**：把符号引擎的验证结果作为可验证奖励，做 **RL / DPO**，让模型内化“长安镇在‘大字’约束下必须被排除”

**优点**：模型学会自主应用约束，减少对符号引擎的每次调用

**缺点**：成本高，且仍需符号引擎兜底保证正确性

### 推荐架构：分层神经符号（最适合你的场景）

```
┌────────────────────────────────────────────┐
│  小模型 SLM（廉价，在线部署）                 │
│  - 解析提示词 → 约束                          │
│  - 生成初始候选（快、省成本）                 │
└──────────────┬─────────────────────────────┘
               ▼ 结构化约束
┌────────────────────────────────────────────┐
│  符号引擎（你的算法，保证正确性）             │
│  - 硬剪枝（长安镇切除）                      │
│  - 先验归一化 → {大朗53%, 大岭山47%}         │
│  - 更新：今天的后验=明天的先验（CRP/高斯）    │
└──────────────┬─────────────────────────────┘
               ▼ 验证结果
┌────────────────────────────────────────────┐
│  大模型 LLM（可选，复杂/歧义时）              │
│  - 处理符号引擎标记的歧义候选                 │
│  - 生成解释                                  │
└────────────────────────────────────────────┘
```

**为什么这样分**：

- **小模型**处理 90% 的常规解析（成本低）
- **符号引擎**保证 100% 的约束正确性（长安镇绝不会漏出）
- **大模型**只在歧义时介入（避免不必要的成本）

这符合“small model + symbolic grounding”的实证优势，以及“symbolics constrain, LLM generates”的范式。

## 约束解码最小 Demo：长安镇 token 被置 -∞

### 核心机制（一句话）

**在 softmax 之前，把违反约束的 token 的 logit 设为 `-∞`，软max 后其概率为 0，结构上无法被采样到**。

```
pythonimport numpy as np

# ============================================================
# 0. 模拟"模型生成的原始 logits"（vocab 是地名 token 集合）
#    无约束时, 模型按高频先验给长安镇很高的 logit (6.5, 排第一)
# ============================================================

# vocab: token id -> 名字
vocab = {
    0: "长安镇",   # 无约束时先验最高
    1: "大朗镇",
    2: "大岭山镇",
    3: "虎门镇",
    4: "厚街镇",
    5: "常平镇",
    6: "长安",     # 注意: 这是"长安"的前缀 token (演示层级)
    7: "大字",
    8: "图书馆",
    9: "东莞",
}

# 模型原始 logits —— 无约束时长安镇最高 (6.5)
logits_raw = np.array([
    6.5,   # 0 长安镇  ← 高频先验, 排第一
    5.8,   # 1 大朗镇
    5.5,   # 2 大岭山镇
    5.2,   # 3 虎门镇
    4.9,   # 4 厚街镇
    4.6,   # 5 常平镇
    6.0,   # 6 长安(前缀)
    4.0,   # 7 大字
    3.5,   # 8 图书馆
    3.0,   # 9 东莞
])

# ============================================================
# 1. 约束知识库: 每个镇必须满足的硬条件 (0/1 门控)
# ============================================================

# 约束: 提示词里有 "大字" 和 "图书馆"
constraints = {"大字", "图书馆", "镇"}

# 每个镇的 "镇名完整形式" 及它满足的约束
towns = {
    0: ("长安镇",   {"镇", "长安"}),                  # 无大字, 无图书馆 → 不满足
    1: ("大朗镇",   {"镇", "大字", "图书馆"}),          # ✓ 满足全部
    2: ("大岭山镇", {"镇", "大字", "图书馆"}),          # ✓ 满足全部
    3: ("虎门镇",   {"镇", "虎门"}),
    4: ("厚街镇",   {"镇", "厚街"}),
    5: ("常平镇",   {"镇", "常平"}),
}

def softmax(x):
    """数值稳定的 softmax"""
    e = np.exp(x - x.max())
    return e / e.sum()

# ============================================================
# 2. 无约束解码 (baseline): 长安镇靠高频先验胜出
# ============================================================
print("=" * 66)
print("场景 A: 无约束 (只有'镇') —— baseline")
print("-" * 66)
probs_raw = softmax(logits_raw)
print("softmax 后概率 (前几名):")
for i in np.argsort(-probs_raw)[:4]:
    print(f"   {vocab[i]:<6s}  {probs_raw[i]:.1%}")
print(f"   → 长安镇 胜出 (先验最高)")

# ============================================================
# 3. 约束解码: 先硬剪枝(门控), 再把非法 token 的 logit 置 -inf
# ============================================================
print()
print("=" * 66)
print("场景 B: 有约束 {大字, 图书馆, 镇} —— 约束解码生效")
print("-" * 66)

# 3a. 阶段一: 硬剪枝 (对每个完整镇名做 0/1 门控)
def gate(town_id):
    name, feats = towns[town_id]
    # 硬约束: 必须满足所有约束词
    ok = all(c in feats for c in constraints)
    # 还要是完整镇名 (排除"长安"这种孤立前缀 token)
    return ok and name.endswith("镇")

# 3b. 构造 mask: 满足约束的 token → True (保留), 否则 → False (屏蔽)
mask = np.array([gate(i) for i in range(len(logits_raw))])

print("约束检查 (token → 是否合法):")
for i in range(len(logits_raw)):
    flag = "✓" if mask[i] else "✗ 屏蔽"
    print(f"   {vocab[i]:<6s} {flag}")

# 3c. 应用 mask: 非法 token 的 logit 置 -inf
logits_masked = np.where(mask, logits_raw, -np.inf)

# 3d. softmax 重归一化 (只在幸存者之间分配概率)
probs_masked = softmax(logits_masked)

print()
print("softmax 后 (非法 token 概率 = 0):")
for i in np.argsort(-probs_masked)[:4]:
    print(f"   {vocab[i]:<6s}  {probs_masked[i]:.1%}")

# 长安镇的命运
print()
print(f"   ★ 长安镇 logit: {logits_raw[0]} → 被置为 -inf")
print(f"     softmax 概率: {probs_masked[0]:.0%}  (结构性为 0, 无法被采样)")
print(f"   ★ 幸存: 大朗镇 {probs_masked[1]:.1%}, 大岭山镇 {probs_masked[2]:.1%}")
print(f"     → 约束解码从源头阻止长安镇, 无需事后纠错")

# ============================================================
# 4. 模拟采样: 证明"长安镇永远抽不到"
# ============================================================
print()
print("=" * 66)
print("场景 C: 采样验证 (1000 次) —— 长安镇抽到次数 = 0")
print("-" * 66)
rng = np.random.default_rng(42)
samples = rng.choice(len(probs_masked), size=1000, p=probs_masked)
counts = np.bincount(samples, minlength=len(probs_masked))
for i in np.argsort(-probs_masked)[:4]:
    print(f"   {vocab[i]:<6s}  采样 {counts[i]:>3d}/1000  ({probs_masked[i]:.1%})")
print(f"   ★ 长安镇采样次数: {counts[0]} → 结构性 0, 无法生成")
```

## Dog 概念空间：有限集合版算法骨架

```
python"""
Dog 概念空间 —— 有限集合版
=================================================
关键假设：概念空间的支撑集是有限的、可枚举的，总规模 ≤ 10万级
        （如 WordNet 名词概念 ≈ 8万 个）

推论：先验 = 有限表 + 计数，而非概率密度
      CRP/高斯/DP 只在"真·集合外出现新值"(黑天鹅)时才需要
"""

class FiniteConceptSpace:
    """
    有限概念空间：
    - 每个概念的取值空间是预先枚举的有限集合
    - 先验 = {值: 计数} 稀疏字典
    - 在线增量贝叶斯：今天的后验 = 明天的先验
    """

    def __init__(self, dims, universe_size_hint=100_000):
        """
        dims: {维度名: 有限取值集}
        例如 Dog 概念空间：
          dims = {
            "品种": {金毛, 柯基, 边牧, 中华田园犬, ...},   # 有限几百种
            "大小": {小型, 中型, 大型, 巨型},             # 有限几个档
            "颜色": {黑, 白, 黄, 棕, 花, ...},           # 有限几十种
            "智力": {低, 中, 高},                         # 有限
            "忠诚度": {低, 中, 高},                       # 有限
          }
        """
        self.dims = dims
        # 每个维度的先验: {值: 出现次数} (稀疏, 只存见过的)
        self.counts = {name: {} for name in dims}
        # 全局未见过集合 (黑天鹅留名表)
        self.black_swan = {}   # 维度名 -> 没见过但出现过的值

    # ====================================================
    # 1. 观测注入: 在线增量更新 (今天的后验 = 明天的先验)
    # ====================================================
    def observe(self, dim, value, weight=1.0):
        """
        看到一个观测值:
        - 若在有限支撑集内 → 计数 +1 (查表, O(1))
        - 若在支撑集外 (黑天鹅) → 进 black_swan 留名 (CRP 式)
        """
        if value in self.dims[dim]:
            self.counts[dim][value] = self.counts[dim].get(value, 0) + weight
        else:
            # 黑天鹅: 先验里没有, 但出现了 → 留名
            self.black_swan.setdefault(dim, {})
            self.black_swan[dim][value] = self.black_swan[dim].get(value, 0) + weight

    # ====================================================
    # 2. 推理: 先验归一化 (有限表直接除)
    # ====================================================
    def prior(self, dim, value):
        """P(值) = n_k / (N + α), 一个除法"""
        N = sum(self.counts[dim].values())
        n = self.counts[dim].get(value, 0)
        alpha = 1.0   # 平滑
        return (n + alpha) / (N + alpha * len(self.dims[dim]))

    def predict(self, dim):
        """对某维度做预测: 归一化后取最可能值"""
        total = sum(self.prior(dim, v) for v in self.dims[dim])
        probs = {v: self.prior(dim, v)/total for v in self.dims[dim]}
        return probs

    # ====================================================
    # 3. 整体概念联合概率 (各维度独立乘积)
    # ====================================================
    def joint(self, assignment):
        """P(大小, 品种, 颜色...) = Π P(维度|值)"""
        p = 1.0
        for dim, value in assignment.items():
            p *= self.prior(dim, value)
        return p

# ============================================================
# 实例化: Dog 概念空间 (有限支撑集)
# ============================================================

    "大小": ["小型", "中型", "大型", "巨型"],
    "颜色": ["黑色", "白色", "黄色", "棕色", "花色", "灰色"],
    "智力": ["低", "中", "高"],
    "忠诚度": ["低", "中", "高"],
})

# 注入观测 (语料频率)

#    用软隶属度作为分数计数注入

class Posterior:
    """后验: 在固定先验基础上, 用软观测分数更新计数"""

    def __init__(self, explicit_prior):
        self.prior = explicit_prior
        # 后验计数 = 先验计数 + 观测注入 (从固定先验出发)
        self.counts = {d: dict(c) for d, c in explicit_prior.dims.items()}
        self.black_swan = defaultdict(lambda: defaultdict(float))  # 黑天鹅留名

    def observe_soft(self, dim, soft, weight=1.0):
        """
        注入一个软观测 {取值: 隶属度}:
        - 在支撑集内 → 分数计数注入 (高斯软映射的产物)
        - 支撑集外 (黑天鹅) → CRP 式留名
        """
        for value, membership in soft.items():
            if value in self.counts[dim]:
                self.counts[dim][value] += membership * weight
            else:
                # 黑天鹅: 先验里没有但出现了 → 留名
                self.black_swan[dim][value] += membership * weight

    def observe_hard(self, dim, value, weight=1.0):
        """硬观测: 已知确切取值 (如"金毛")"""
        if value in self.counts[dim]:
            self.counts[dim][value] += weight
        else:
            self.black_swan[dim][value] += weight

    def posterior(self, dim, value):
        """P(值|观测) = (先验频数 + 后验注入) / 总计数  —— 一个除法"""
        total = sum(self.counts[dim].values())
        return self.counts[dim][value] / total if total else 0.0

    def predict(self, dim):
        total = sum(self.counts[dim].values())
        return {v: c / total for v, c in self.counts[dim].items()}

pythonimport numpy as np
from collections import defaultdict

# ============================================================
# 目标: 把 DP-mixture 真正加进"大小"维度
#
# 之前: "大小"是固定档位 {小型/中型/大型/巨型}, 高斯软映射
# 现在: "大小"是连续身高, 观测可能形成先验中没有的新身高中心
#      → DP-mixture 用中国餐馆过程(CRP)动态开新分量
#
# 关键: 概念取值有限 ≠ 每个维度的观测中心固定
#      "大小"的真实中心(身高分布峰) 是未知的、可能随数据增长
#      DP-mixture 自动发现: 新身高密集区 → 开新高斯分量
# ============================================================

# ============================================================
# 1. 高斯分量 (每个"大小簇" = 一个高斯: 均值+方差)
# ============================================================

class GaussianComponent:
    """一个高斯分量: 代表一个"大小簇"(身高中心)"""

    def __init__(self, mu, sigma_sq):
        self.mu = mu          # 身高中心
        self.sigma_sq = sigma_sq  # 方差
        self.n = 0            # 该簇的观测数

    def log_density(self, x):
        """高斯对数密度"""
        return -0.5 * (np.log(2*np.pi*self.sigma_sq)
                       + (x - self.mu)**2 / self.sigma_sq)

    def update(self, x, weight=1.0):
        """吸收一个观测 (更新均值/方差, 一个贝叶斯增量)"""
        new_n = self.n + weight
        # 在线更新均值 (Welford 式)
        delta = x - self.mu
        self.mu += delta * weight / new_n
        # 在线更新方差 (近似)
        self.sigma_sq = ((self.n) * self.sigma_sq
                         + weight * (x - self.mu)**2) / new_n
        self.n = new_n

    def __repr__(self):
        return f"G(mu={self.mu:.0f}, var={self.sigma_sq:.1f}, n={self.n:.0f})"

# ============================================================
# 2. DP-mixture 分量管理器 (中国餐馆过程: 开新桌)
# ============================================================

class DPMMSizeDimension:
    """
    "大小"维度的 DP-mixture:
    - 已发现的身高中心 → 高斯分量 (可复用, 概率 ∝ n_k)
    - 新高身高 → 开新分量 (概率 ∝ α)
    - 这就是"连续维度开新分量", 不同于离散维度的 CRP 类别
    """

    def __init__(self, alpha=1.0, base_mu=70, base_sigma_sq=100):
        self.alpha = alpha          # 浓度参数: 越大越容易开新分量
        self.components = []        # 已发现的分量列表
        self.base_mu = base_mu      # 新分量的先验均值 (base measure G0)
        self.base_sigma_sq = base_sigma_sq

    def _open_new(self, x):
        """开新分量: 从 base measure 抽参数, 以 x 为初始中心"""
        # 新分量中心 = 观测本身 (贴近数据), 方差 = base 方差
        comp = GaussianComponent(mu=x, sigma_sq=self.base_sigma_sq)
        self.components.append(comp)
        return comp

    def observe(self, x, weight=1.0):
        """
        注入一个连续身高观测 x:
        - 以 ∝ n_k/(N-1+α) 加入已有分量 (数据密集处复用)
        - 以 ∝ α/(N-1+α) 开新分量 (新身高密集区)
        这是"开新分量"的核心决策
        """
        N = sum(c.n for c in self.components)

        # 计算每个已有分量的加入概率 + 开新分量概率
        scores = []
        for c in self.components:
            # ∝ 已有观测数 + 高斯似然 (软分配)
            scores.append(c.n + weight * np.exp(c.log_density(x)))
        # 开新分量 ∝ α
        scores.append(self.alpha)

        # 归一化成概率
        total = sum(scores)
        probs = [s/total for s in scores]

        # 采样/选择: 落在哪个分量
        choice = np.random.choice(len(scores), p=probs)
        if choice == len(self.components):
            # 选到了"新桌" → 开新分量
            comp = self._open_new(x)
            comp.update(x, weight)
            opened = True
        else:
            comp = self.components[choice]
            comp.update(x, weight)
            opened = False
        return comp, opened

    def predict_density(self, x):
        """在新观测 x 处, DP 混合的预测密度 = Σ (权重 × 高斯密度)"""
        total_w = sum(c.n for c in self.components) + self.alpha
        return sum(
            (c.n / total_w) * np.exp(c.log_density(x))
            for c in self.components
        ) + (self.alpha / total_w) * np.exp(
            -0.5*((x - self.base_mu)**2)/self.base_sigma_sq
        ) / np.sqrt(2*np.pi*self.base_sigma_sq)

    def summary(self):
        print(f"   已发现分量数: {len(self.components)}")
        for c in self.components:
            print(f"   {c}")

回顾之前三层：

1. **固定先验**（有限表）→ `ExplicitPrior`
2. **输入不确定性**（高斯软映射）→ `GaussianSoftMapper`
3. **无限多样的后验** → 现在由 **DP-mixture 补齐核心**：

这和你之前纠正的“CRP 只用于离散维度”精准对应：

- **离散维度**（品种/颜色）→ CRP 类别，有限取值，黑天鹅留名
- **连续维度**（大小）→ **DP-mixture 开新高斯分量**，无限身高中心，数据驱动增长

**开新分量的机制就是中国餐馆过程**：新观测以 ∝ `n_k/(N-1+α)` 复用已有分量，以 ∝ `α/(N-1+α)` 开新分量。α 越大越爱开新桌。

## WordNet 对构建概念空间先验的真实帮助

先明确结论：**有帮助，但不是全部。它主要帮你搭「概念骨架」和「离散先验」，帮不上「连续先验」和「后验」。** 我按能帮/帮不上拆开讲。

### 一、WordNet 是什么（数据层面）

- **规模**：155,287 个词、117,659 个 synset、206,941 个词义对。其中名词 117,798 词 / 82,115 个 synset
- **synset** = 一组同义词，代表一个概念（如 {night, nighttime, dark} 是一个 synset）
- **每个 synset 带 gloss**（自然语言定义）+ 例句
- **层次结构**：通过上位词/下位词（is-a 关系）组织成树，如 car → motor_vehicle → wheeled_vehicle → … → entity
- **其他关系**：part-of（整体部分）、is-made-of（物质构成）等
- **多语种**：不止英语，全球有很多 WordNet（Open Multilingual WordNet）

这些数据里，对你的概念空间先验**有直接价值**的：

### 二、能帮上的 4 件事

**1. 枚举「概念空间」的取值候选（你已验证过的那条线）**

这是最直接的一环。你要的「输出空间可枚举、总数 ≤10 万」，WordNet 就是候选来源之一：名词 8.2 万 synset ≈ 8.2 万概念节点，正好落在你之前判断的「≤10 万」区间。它提供的是**离散概念的候选全集**，可以灌进你的 `ExplicitPrior` 有限先验表。

**2. 提供「先验结构」——不只是平铺的取值表，而是层次**

WordNet 的 is-a 树给了你**概念之间的上下位关系**。这对先验的意义很大：你的先验不该是一张「平铺的 8 万取值表」，而应是一棵带继承的树。比如「狗」是「犬科」的下位、「犬科」是「哺乳动物」的下位。先验概率可以在树上传播（父节点承接子节点），这比平铺表更有信息量。

**3. 提供「语义定义」（gloss）→ 作为观测→概念的映射锚点**

每个 synset 的 gloss 是自然语言定义。这能帮你把**观测文本 → 概念**的映射做实：一个描述「大型犬，毛茸茸，爱叫」的观测，能通过 gloss 里的词命中「狗.n.01」这个 synset。这是 `GaussianSoftMapper` 之外的另一种软映射锚点。

**4. 提供「词义频率」作为频率先验的种子**

WordNet 标注了每个词义的相对频率（reference corpus 中的出现次数）。这正好可以给你的「频率先验」当种子——`ExplicitPrior` 里每个概念的先验概率，不必全手工设定，可以直接用 WordNet 的词义频率初始化。

### 三、帮不上的 3 件事（关键边界）

**1. 连续属性（大小）的先验——WordNet 完全没有**

WordNet 是**词汇-概念**数据库，只编码「是什么」（is-a）关系。它不编码「身高 30cm vs 85cm 的概率分布」。你刚做的 DP-mixture「大小」维度，WordNet 帮不上——这正是为什么你需要 `GaussianSoftMapper` + DP-mixture 自己建模连续维度。**WordNet 管「有哪些概念」，不管「连续属性怎么分布」。**

**2. 后验——WordNet 全是先验，没有后验**

WordNet 是静态的、编纂好的词库，代表「一个语言社区共享的先验结构」。它不含、也不该含「某个特定用户/场景下观测堆积出来的后验」。你的架构里「今天后验=明天先验」的增量过程，WordNet 管不了——它是**先验的来源**，不是**后验的容器**。

**3. 常识性软约束（地理、物理规律）——WordNet 只有词间关系**

你之前做的「东莞 28 镇」「直筒子市」「长安镇结构性不可采样」这类地理/常识约束，WordNet 里没有。它是语言本体，不是常识知识库。这类硬约束需要别的资源（如 GeoNLP、GeoNames、常识知识库 ConceptNet）或你手工编码。

### 四、给你的定位建议

把 WordNet 放进你架构里，它的位置是**「离散概念层的先验骨架来源」**：

```
概念空间先验 = WordNet(离散概念+层次+gloss+词义频率)
             + 你自己编码的连续属性先验(大小→高斯)
             + 你手工编码的硬约束(地理/常识)
后验        = 观测注入, DP-mixture 动态开新分量
```

WordNet 解决的是你「有限先验表」里**离散那半**的实际数据来源——给你 8 万概念的候选全集、层次结构和频率种子。但它**填补不了连续属性先验、后验、和常识硬约束**这三块，那些仍是架构里需要你自己建模的部分。

pythonimport json

# ============================================================
# 目标: 把 WordNet 的 is-a 树真正接入 ExplicitPrior
#
# 之前: ExplicitPrior = 平铺查表 (固定先验表, 8万项)
# 现在: 先验 = 概念树 + 每节点传播概率
#       - 只需给 根/上层节点 显式设先验
#       - 下层节点概率 = 沿 is-a 路径累乘传播因子
#       - 从 8万平铺表 → 压缩为 树结构 + 少量根先验
#
# 对应 WordNet 事实:
#   - synset 经 is-a(上下位) 组成树 [5](@index-ref?id=5)[1](@index-ref?id=6)
#   - 子节点是父节点的下位, 所有子实例都是父实例 [1](@index-ref?id=7)
#   - 名词空间 82,115 节点可抽成树, 节点即假设 [4](@index-ref?id=8)
# ============================================================

class WordNetConceptNode:
    """概念树上的一个节点 = 一个 synset"""

    def __init__(self, synset_id, name):
        self.synset_id = synset_id   # e.g. "dog.n.01"
        self.name = name
        self.children = []           # 下位词 (hyponyms)
        self.parent = None
        self._prior_set = None       # 显式设置的先验 (只在根/上层)

    def add_child(self, child):
        self.children.append(child)
        child.parent = self

# ============================================================
# 先验: 树结构 + 传播规则 (不是平铺表!)
# ============================================================

class TreePrior:
    """
    概念树先验:
    - 只在根节点显式设先验 P(root)
    - 每个父节点带"子节点分摊比例" (children_weight, 归一化后=传播因子)
    - 任意下层节点的先验 = 从根沿路径累乘传播因子
    - 这就是"沿上下位传播", 而非平铺查表
    """

    def __init__(self, root_prior=0.5, spill=0.1):
        self.roots = []
        self.root_prior = root_prior   # 根概念总先验
        self.spill = spill             # 落到"其他/未列出"的残余概率

    def register_root(self, node, weight):
        """注册根节点 + 它的先验权重"""
        self.roots.append((node, weight))

    def _propagate(self, node, acc_prob, path):
        """
        沿 is-a 树传播概率:
        - acc_prob = 父节点累乘到当前的先验
        - 对每个子节点, 按 children_weight 分摊
        返回 {synset_id: 先验概率} (该子树的所有节点)
        """
        result = {node.synset_id: acc_prob}

        # 该节点的子节点权重
        total = sum(cw for _, cw in node.children)
        if total == 0:
            return result  # 叶子, 概率不再往下传

        # 每个子节点按权重分摊父节点概率
        for child, cw in node.children:
            child_prob = acc_prob * (cw / total)
            result.update(self._propagate(child, child_prob, path + [child.name]))
        return result

    def build_full_prior(self):
        """把整棵树摊平成 {synset_id: prior} 查表 (但来源是传播!)"""
        full = {}
        for root, w in self.roots:
            root_prob = self.root_prior * (w / sum(rw for _, rw in self.roots))
            full.update(self._propagate(root, root_prob, [root.name]))
        return full

    def prior(self, synset_id):
        """查询某概念的先验 (沿路径传播得到)"""
        return self.build_full_prior().get(synset_id, self.spill)

# ============================================================
# 构建一个真实的 WordNet 式 is-a 树: 犬科 → 狗 → 品种
# ============================================================

def build_canine_tree():
    """
    模拟 WordNet is-a 子树:
    entity(根) → mammal → canine → dog → {chihuahua, labrador, ...}
    层次即上下位关系 [5](@index-ref?id=9)[1](@index-ref?id=10)
    """
    entity = WordNetConceptNode("entity.n.01", "实体")
    mammal = WordNetConceptNode("mammal.n.01", "哺乳动物")
    canine = WordNetConceptNode("canine.n.02", "犬科动物")
    dog    = WordNetConceptNode("dog.n.01", "狗")
    wolf   = WordNetConceptNode("wolf.n.01", "狼")
    fox    = WordNetConceptNode("fox.n.01", "狐狸")

    chihuahua = WordNetConceptNode("chihuahua.n.01", "吉娃娃")
    labrador  = WordNetConceptNode("labrador.n.01", "拉布拉多")
    poodle    = WordNetConceptNode("poodle.n.01", "贵宾犬")

    # 搭建 is-a 树 (用 (node, weight) 记录子节点分摊权重)
    entity.add_child((mammal, 0.8))
    entity.add_child((WordNetConceptNode("plant.n.02", "植物"), 0.2))

    mammal.add_child((canine, 0.1))
    mammal.add_child((WordNetConceptNode("feline.n.01", "猫科"), 0.3))
    mammal.add_child((WordNetConceptNode("primate.n.01", "灵长类"), 0.6))

    canine.add_child((dog, 0.4))
    canine.add_child((wolf, 0.35))
    canine.add_child((fox, 0.25))

    dog.add_child((chihuahua, 0.2))
    dog.add_child((labrador, 0.5))
    dog.add_child((poodle, 0.3))

    return entity

# ============================================================
# 演示: 平铺查表 vs 树传播
# ============================================================

print("=" * 72)
print("先验传播: 概念树 (is-a) 而非平铺查表")
print("=" * 72)

tp = TreePrior(root_prior=0.5)
tp.register_root(entity, 1.0)   # 只给根实体设先验 = 0.5

# 只有根显式设了先验, 下层全部由传播得出
full = tp.build_full_prior()
print(f"\n  根实体先验(显式设): {tp.root_prior}")
print(f"  落入树的总先验:     {sum(full.values()):.3f}")
print(f"  未列出的残余(spill): {tp.spill}")

print("\n  synset_id          概念    先验概率(传播)  解释")
print("-" * 72)

    name = sid.split(".")[0]
    print(f"  {sid:<18} {name:<8} {p:>8.4f}  ")

print("\n" + "=" * 72)
print("关键: 先验由路径传播, 不是查平铺表")
print("=" * 72)
print(f"  P(吉娃娃) = P(实体)×P(哺乳|实体)×P(犬科|哺乳)×P(狗|犬科)×P(吉娃娃|狗)")
print(f"             = 0.5 × 0.8 × 0.1 × 0.4 × 0.2")

p_chihuahua = (0.5 * 0.8 * 0.1 * 0.4 * 0.2)
print(f"             = {p_chihuahua:.4f}")

print("\n  P(拉布拉多) = 0.5 × 0.8 × 0.1 × 0.4 × 0.5 = ", 0.5*0.8*0.1*0.4*0.5)
print(f"  P(吉娃娃) > P(拉布拉多) 因为拉布拉多是更常见的"狗"子类(权重0.5>0.2)")

print("\n" + "=" * 72)
print("价值: 先验规模从 8万平铺项 → 树结构 + 少量根先验")
print("=" * 72)
print("  平铺表: 需显式设定 82,115 个概念的先验 [6](@index-ref?id=11)")
print("  树传播: 只设 1 个根先验(0.5), 其余全部继承")
print("  若每节点平均 5 个子, 显式设定数 = 树层数, 而非节点数")

# 展示传播因子如何让概率"越往下越具体但越小"
print("\n  概率沿路径递减 (越具体越小的先验, 符合直觉):")
for name, p in [("实体", full["entity.n.01"]),
                ("哺乳", full["mammal.n.01"]),
                ("犬科", full["canine.n.02"]),
                ("狗",   full["dog.n.01"]),
                ("吉娃娃", full["chihuahua.n.01"])]:
    print(f"    {name:<4} → {p:.4f}")
