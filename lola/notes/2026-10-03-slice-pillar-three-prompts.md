切片柱阵·三图提示词（ima Copilot 图库）配套术语碑 v5 条目「切片柱阵 Slice-Pillar Array（艺名 对决柱林 Duel-Pillar Grove）」。
视觉语法锁定：纵向堆叠实体行（顶→底）＋ 共享横向切片轴 ＋ 立起方柱（柱高＝信号）。
用途：白天开工时把下方中文提示词直接贴进 ima Copilot 图库，生成概念示意图；若要精确数据图，再改用 Python / Gosling 按真实数据重画（图1 可用 Wordbank 常模、图3 可用各代产品公开规格）。
注意：图像生成出的是"风格/概念示意"，不是精确数据图。图1 · 儿童语言发育柱阵一幅科学信息图风格的「切片柱阵」可视化：纵向从上到下排列 5 行，每行是一个语言发育维度——分别是「词汇量」「平均句长 MLU」「词类多样性」「句法复杂度」「指代清晰度」；横向是从左到右的月龄切片轴，底部清晰标注 12、18、24、30、36 个月。每个单元格里立起一根方形柱子，柱高表示该维度在该月龄的掌握度或出现频率，整体呈现随月龄增大柱子明显「发育爬坡」的趋势。浅色干净背景、细网格线，左侧行标签与底部轴标签清晰，配色用柔和的婴幼儿蓝绿渐变。风格：严谨但友好的科研信息图，类似发展心理学教科书插图，不要卡通、不要 3D 透视。图2 · 生物体 time-spine（生命尺度柱阵）一幅「切片柱阵」式的生命尺度信息图：纵向从上到下排列 5 行生物——昆虫（如果蝇）、爬行动物（如龟）、小型哺乳（如鼠）、人、大象（可加鲸）；横向是生命阶段切片轴，分「卵 / 幼体 / 亚成体 / 成体 / 老年」五格（或标为对数年龄轴）。每行的方柱只立在该物种实际经历的生命阶段格内，柱高表示该阶段的体型／代谢／发育里程碑强度——昆虫的整段生命只占据最左一两格（极短 lifespan），而大象的柱子从左铺到最右（极长 lifespan），直观呈现不同物种 lifespan 跨度的巨大差异。浅色背景、科学插画风，左侧物种名配小图标、底部阶段标签。风格：自然博物馆展板 / 科普信息图，干净、克制。图3 · 技术迭代柱阵（GPU NVIDIA vs AMD ＋ iPhone）一幅「切片柱阵」式的技术迭代对决图：纵向排列多行——第一行 NVIDIA GPU 世代（GTX → RTX 20 → 30 → 40 → 50 系），第二行 AMD GPU 世代（对应代际的 RX 系列），第三行起 iPhone 世代（iPhone 4 → … → 16）。横向是发布年份切片轴，底部标注 2010、2015、2020、2025。每行在对应年份格立起方柱，柱高表示算力（TFLOPS）／显存带宽／芯片性能；两列 GPU 行左右并跑，形成「对决柱林」的竞速感（呼应 PK／对决柱林），iPhone 行另展示消费电子的迭代节奏。浅色科技感背景、细网格，左侧行标签、底部年份轴，NVIDIA 用绿、AMD 用红、Apple 用银灰做区分色。风格：半导体行业 / 科技财报信息图，干净专业，不要卡通。白天开工顺序与数据来源目标：把「切片柱阵」沉淀为固定的思考 / 展现工具，白天围绕它出一系列图。推荐开工顺序图1 儿童语言发育柱阵（最优先）：有真实数据，最扎实；出图后可直接喂《智能＝扩张性的交互过程》实验方案·沙盒 A。图2 生物体 time-spine（概念性）：先把"跨尺度 lifespan 怎么同框"讲清楚，是 切片轴律 的现场教学。图3 技术迭代柱阵（代际对决）：NVIDIA vs AMD 的"对决柱林"接 PK 律，iPhone 行展消费电子节奏。各图数据来源（精确图重画时用）图1：Wordbank（词汇发育常模，Frank et al. 2017，wordbank.stanford.edu）＋ CHILDES（Zhou3 为唯一中文典型发育儿童纵向语料，其余多为横断面；ASD 语料可作扰动/对照）。柱高可挂 词汇量 / MLU / 词类多样性 / 句法复杂度。限制：仅限研究、非商业。图2：概念性示意为主；若要做准，用各物种 lifespan 与发育里程碑公开资料，按「生命阶段格」bin 切片（勿用等距年龄轴，否则昆虫被压成一条线、大象溢出）。图3：各代产品公开规格——NVIDIA（GTX→RTX 20/30/40/50 系）、AMD（对应 RX 系列）、iPhone（4→…→16）的发布年、算力(TFLOPS)、显存带宽。两条铁律（白天别忘）图库（ima Copilot 图库）出的是概念/风格示意，不是精确数据图；要精确版改用 Python / Gosling 按真实数据重画。切片怎么 bin，柱阵就讲什么故事——切片轴律优先于美观。
