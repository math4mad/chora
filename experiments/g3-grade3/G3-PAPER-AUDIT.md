# G3-Paper 审计 · 落架退化（园笔 2026-10-09）

> 中炮准备中普查 G3-Paper 探针，**发现落架指标退化**。此发现**先于任何中炮/主炮跑分**，务必先修。

## 一 · 发现：6/9 题落架恒真

对 `g3_probe.PROBES` 九题逐题查「候选集之舱号集合」：

| 轴 | 候选舱集合 | 落架是否恒真 |
|---|---|---|
| 空间判别 | {0,1,2,3} | 否 |
| 空间判别 | {0,1,3} | 否 |
| 锚点 | {0,1,2,3} | 否 |
| 序敏 ×3 | {2} | **⚠ 恒真** |
| 三年级验收 ×3 | {3} | **⚠ 恒真** |

**落架恒真题数 = 6/9**。故落架分 = `6 + (余 3 题中对的数)`，**最多只反映 3 题**。

## 二 · 这不是新发现——runbook 早有预警

`runbook.md`「G3-Paper **v1 修正**（金丝雀暴露）」第一条：
> ①序敏/验收轴候选须掺跨舱干扰词，**否则落架恒真**。

**该修正未实施。** 故：
- 金丝雀之「given 落架 8/9 ≈ random 8/9」**主要是 6/9 恒真 + 噪声**，**不能**作为臂间分离之证据。
- 中炮/主炮若照用 v0 探针，落架信号同样**无意义**。

## 三 · 附带发现：探针答案在语料内

九题之金标（守岁/红包/NBA 顺位/三年级事实）**皆在训练语料中出现**——故此卷实为**记熟度测试**，非泛化测试。各臂皆记熟 → 可能**天然无分离**。

## 四 · 修法（G3-Paper v1）

1. **序敏/验收轴掺跨舱干扰词**：候选须含别舱词，使「落架」（选对舱）与「字面」（选对词）**皆有分辨力**。
   - 例：序敏题候选掺「饺子/烧烤/彩虹」等别舱词；验收题掺别舱干扰。
2. **加 hold-out**：至少部分题的答案**不在训练语料**（新词泛化），以测「学结构」而非「背语料」。
3. 落架分**只统计非退化题**（或明确标注 6/9 恒真）。

## 五 · 处置

- **暂缓中炮**：探针 v0 未修，跑也无意义（落架退化 + 记熟测试）。
- **建 G3-Paper v1**（上述三条），**先冻 v1 判据**，再跑中炮。
- 另: 中炮计时实测 **~0.8 s/step**（d512/L8, M1 Pro MPS）；5 臂 × 3000 步 ≈ **3.4h**——规模须与时间一并裁。
