# PREREG_PB15 · 序锦标赛：两两对决排出全局最优入场序

> 状态：候批候射（主人 0923「分语义群/概念空间以后，排列组合去试啊」之授权方向，
> 本册为其省钱版：全排列 5040 → 两两对决 42 跑）。铁律：判据先冻。

## 0. 原理

C42（序决定谁先圈地）若成立，则任意两空间 {X,Y} 间存在**成对胜负关系**：
D(X→Y) = NLL_X(先X后Y) − NLL_X(先Y后X) （对 X 而言，先入是否占优）。
D>0 记 X≻Y。**排序问题 = 锦标赛问题**：n 个空间只需 C(n,2) 场对决，
每场 2 个序各训一次 —— 无需 n! 全排。

## 1. 设计（弹药全部在册）

- 空间集 = exp11 矩阵七臂 {spring, summer, code, legal, medical, mid, general}
  （语料内嵌件现成，0.5B 单臂 ≈ 1 分钟）；
- 对决 = 21 场 × 2 序 = 42 次双域连训（每域 3 epoch 减半预算，够判方向即可）；
- 探针 = 各域 held-out NLL + 重叠方向冲突角（在册几何仪）；
- 全部塞进 4 个 kernel（每 kernel 约 11 场），双席位两小时毕。

## 2. 判据（先冻结）

- **J1（成对可判）**：≥16/21 场 D 的符号跨双 seed 一致 —— 否则 C42 之"序"效应
  低于噪声，全案记 ✗；
- **J2（可传递性=锦标赛合法性）**：胜关系 ≻ 无环（C37 语义：θ₀ 同族可比）。
  有环 → 序效应非全序，"最优序"不存在，只存在**循环生态**（本身是大发现，单记）；
- **J3（排序预测力验证）**：按 ≻ 拓扑序排出全局序 O*，抽 5 个随机排列对照训练，
  预测 O* 之平均 fresh-probe 排名不劣于任何抽样 —— **用 5 次抽样代替 5035 次全排**；
- **J4（剂量解耦复查）**：每场顺带记 C43 影子 —— 若 D 符号随两域剂量比翻转
  （等剂量时反向），则该场记"序不压剂量"例，汇总成 C42/C43 分界图。

## 3. 输出

- 胜关系矩阵 7×7（有向图入档）+ 拓扑序 O* = **本园第一张"课程表定理"**；
- 报告 report_pb15.json（每 kernel 即吐 REPORT_LINE，日志即幸存者旧制）；
- O* 若稳定 → 直接喂模块二课程设计与 P-B12 旅制臂的批内排布。

## 4. 失败条款

J1 败 → 序效应不存在，C42 降级候审；J2 有环 → 改宣"循环优势生态"，
另开一案（ rock-paper-scissors 式概念空间圈地 —— 若真有环，比排序更值钱）。
