> 故本案**去标记**——域改由**多样内容**承载（古今之轴），试其方向可否**跨词型**迁移。

## 0 · 命题

- **H-p5f**：若「域方向」有**语义**成分，则去标记后，方向应可自训练词型迁移至**未见词型**。
- 若立 → P5 之「跨词型无方向」系**标记承载**之限；去标记则方向现。
- 若破 → 「域方向」在目标词位者，实为**内容**而非**域**；跨词型语义域方向确不存。

## 2 · 设计

- **域轴**：古典 ↔ 现代（**无标记 token**，由多样内容词承载）。
- **域词（古典）**：古籍 / 竹简 / 碑刻 / 宋版书 / 拓片 / 青铜器（每句取一，**多样**）。
- **域词（现代）**：数字资源 / 网络资料 / 电子档案 / 数据库 / 手机导览 / 扫码展签。
- **目标词型**：训练=图书馆；测（未见）=博物馆 / 档案馆。
- **读出位**：**目标词**处（沿 P5）。
- 仪：Qwen2.5-0.5B（快，主）；结果若正，Qwen2.5-1.5B 复证。
- 籽：3；α 归一后扫。

## 3 · 反证条款

- H-p5f-2 立 → 语义域方向**存在**（去标记后现），P5 判词须修。
- H-p5f-2 破 → 目标词位所读者为**内容**非**域**；跨词型语义域方向不存（四案一致）。
- 随机 v 过任一 → 仪器坏，归零。

## 4 · 诚实预验尸

1. 古典/现代内容词本身差异大，方向或只是「这些词」而非「域」。
2. 目标词位读出或仍受词型 identity 干扰。
3. 语料模板构造；证「可/不可」，非经验率。
