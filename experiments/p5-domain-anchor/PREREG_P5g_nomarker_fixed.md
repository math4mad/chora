## 0 · 命题

- **H-p5g**：去标记之域方向，若于**可觉域**之读出位（域词在前）测得，可**跨词型**迁移。
- 若立 → 语义域方向存在，P5 判词须修。
- 若破 → 目标词位所读者为**内容**非**域**；跨词型语义域方向确不存。

## 2 · 设计

- **域轴**：古典 ↔ 现代（无标记 token，多样内容词承载）——同 P5f。
- **域词（古典）**：古籍 / 竹简 / 碑刻 / 宋版书 / 拓片 / 青铜器。
- **域词（现代）**：数字资源 / 网络资料 / 电子档案 / 数据库 / 手机导览 / 扫码展签。
- **模板（域词在前）**：`{O}是{W}最珍贵的收藏` / `这批{O}一直存放在{W}里` /
  `研究{O}的人都爱去{W}` / `{O}让{W}远近闻名`。
- **目标词型**：训练=图书馆；测（未见）=博物馆 / 档案馆。
- 读出位：目标词处；籽 3；α 归一后扫。

## 3 · 反证条款

- H-p5g-2 立 → 语义域方向存在（去标记后现）。
- H-p5g-2 破且 H-p5g-1 立 → 内容位所读为内容非域；跨词型语义域方向不存。
- 若 H-p5g-1 亦破 → 疑读出/设计另瑕，再诊（不径下结论）。

## 4 · 诚实预验尸

1. 古典/现代内容词差异大，方向或只是「这些词」而非「域」。
2. 域词在前但目标词仍近句首者，觉域或不足；前置断言只保「非 token 0」。
3. 语料模板构造；证「可/不可」，非经验率。
