# PREREG P5d《未见标记迁移 · 破循环之证》— 冻本（2026-10-08 园笔自决）

> 母案：P5b 之「省名位泛化 1.000」被自认含**token 同一性循环之嫌**（预验尸#2）。
> 本案正面拆之：若域方向系 group-level（北方→南方），则应可迁移至**训练中从未见过**的省名 token。
> **状态：已冻（2026-10-08 夜）。判据先冻后用。**

## 0 · 命题

- **H-p5d**：域方向若为**群级（group-level）语义轴**，则施于**未见标记**（训练省名之外者）仍立。
- 若立 → P5b 之循环之嫌得解，方向有真语义成分。
- 若破 → 方向确系 token 身份，P5b 之 1.000 循坏之嫌坐实。

## 2 · 设计

- 方向轴：**北方→南方**（语义群级）。
- 训练标记：北={黑龙江, 吉林}，南={广东, 广西}。
- **未见标记（测试）**：北'={辽宁}，南'={海南}。
- 语料：中性句（同模板，唯省名异）→ 唯标记为域信号。
- 读出位：**省名位**（沿 P5b）。仪：GPT-2（快）；若结果暧昧，Qwen2.5-0.5B 复证。
- 籽：3；α 归一后扫。

## 3 · 反证条款

- H-p5d-2 立 → 方向为群级语义轴，P5b 循环之嫌得解。
- H-p5d-2 破 → 方向系 token 身份；P5b 之 1.000 不得读作语义泛化。
- 随机 v 过任一换义判 → 仪器坏，归零。

## 4 · 诚实预验尸

1. 「北方/南方」在地理/语言上非严格二分（辽宁近东北、海南极南），轴未必干净。
2. 中性语料使标记成**唯一**信号，或放大 token 效应。
3. GPT-2 对中文省名无语义组织；本案若过，须防其系位置/频率效应。
