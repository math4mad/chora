# PREREG P-B19《最小必要维度 MRD》— 冻结于 2026-09-25（主人晚谈提案，判词照录）
> 提案判词（主人原话存档）：「既然这个现象在四类数据上都能复现……逐步提高 r，观察 ΔW 方向什么时候开始收敛。
> 收敛时的 r 值，本质上就是这组数据的'最小必要维度'……反过来用——用 ΔW 收敛所需的 r 值，度量数据集的结构复杂度。」
> 立梁门：答梁三（序与生长）之问「结构在权重里占几根弦」；若判否——量尺钝化，MRD 概念降级候审。

## 0. 定义（先冻）
对数据集 D，在固定基座/配方下扫 r ∈ {2,4,8,16,32,64}（α=2r 惯例，与在册 r=16/α=32 单点重合可比）：
- **MRD_energy(D)** = 最小 r，使新增方向能量占比 ε(r) = E(超出 k90(r) 的方向)/E(全部) < 5%；
- **MRD_angle(D)** = 最小 r，使 ΔW(r) 与 ΔW(2r) 的 top-k 子空间主夹角 < 10°（嵌套稳定=方向收敛）；
- **MRD_res(D)** = 双胞胎卡 L4/L5 分离度首次达到 r=64 读数的 90% 之最小 r；
- 三读数并报，**不许挑好看的当 MRD**（若三者分歧 > 2 档，记"复杂度多维"，本身即发现）。

## 1. 四数据集（呈现结构维度各异——本案自变量）
| 集 | 结构 | 预期 MRD |
|---|---|---|
| D1 选秀 (NBA 年×顺位) | **二维**（模板确定性生成，corpusgen 在册） | 中（≈4-8） |
| D2 代际演进 (iPhone/Intel 单线年表) | **一维** | 最小（≈2-4） |
| D3 字母序 (同词表按拼音/字母排) | **零任务结构**（纯呈现序对照） | **不收敛**（角度漂移恒 >10°） |
| D4 春节语料 (55 条语义群) | 语义弥散 | 最大或半收敛 |
**核心预测**：收敛**本身**是结构的证据——D3 永不收敛；MRD(D2) < MRD(D1)（维度数≈结构维度+语义残余）。若序不占维（C49 落空），MRD(D1)≈MRD(D2)≈MRD(D3)，量尺判死。

## 2. 仪器与纪律
- 0.5B-instruct 单 kernel 串行 24 训（每训 6ep，估 3-6min）+ 每训后四读数；
- 疫苗行必 `2>/dev/null`（P-B18 血案：`2>/dev` 假卸载）；挂载断言+SELFTRAIN 内检随行；
- 每 r 存 ΔW 全量 safetensors（>1KB 铁律）+ sha；报告含 _selfcheck=pb19_ok；
- 卡用 P-B18 双胞胎卡（sha 512f9869）D4 段 + 各集自铸近重复对（同卡法五档，模板确定性生成）。

## 3. 归零与失败条款
- 三 MRD 全平（四集同值）→ 量尺钝，本案降为观察记录，C49 判词不受累（其另有卡测）；
- D3 也收敛 → 说明"字母序"本身是任务结构（序即数据律反噬！）——如实记，改判据重议；
- seed 漂移 > 相邻 r 档差 → 全部归零，先加 seed 再说话。
