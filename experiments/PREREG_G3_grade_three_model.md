# PREREG·G3 三年级模型 the Grade-Three Probe（案号候朱批，暂占 PB17）

**立项口谕**（主人 2026-09-24 暮，最高证据级亲口）：
> "就说我们不需要那个大的参数量，注意力机制需要，**不要模型自己去注意，我们给他注意力**。测试集也是**有限指空间测试集**。就训练**小学三年级模型**。"

## 假设
H：参数量非阶段智能之承重墙。**给定的注意力**（结构化语料=设计者预烧的"该看哪"）+ 有限指空间验收下，**≤0.15B 参数、≤1B token** 的从零模型可通过"小学三年级"探针卷；同 token 预算之随机/麻辣烫语料臂显著失败。

## 三臂设计
- **主臂·快餐**：corpusgen 量产分舱语料——每舱一概念空间（春节/夏天/路边摊/超市/自然/社会……），短文档、边界明、**序即维度**（正序供入，one by one 课程门控：幼儿舱→二年级舱→三年级舱）。
- **副臂·给定注意之硬版**：舱间块对角掩码/分段偏置——设计者直接规定谁能看见谁（输入层注意=结构，参数层注意=先验）。
- **对照臂·麻辣烫**：同舱同量 token，混洗一锅烩，无课程无边界。

## 模型
Qwen2.5-0.5B 同构缩比（d≈768、层≈12、~120-150M），从零训。金丝雀先行：0.03B@100M token 校吞吐与 loss 形状。

## 测试集（有限指空间卷·G3-Paper）
闭集轴已知，自动判分，**判据先冻于任何一臂跑分之前**（PB16 律）：
1. **空间判别**：给词判舱（春节×夏天型，含新词泛化）；
2. **锚点检索**：球门-钥匙式最近邻/MaxSim 题；
3. **序敏**：NBA 型——正/逆/乱三序下的一致性（打乱即变者过）；
4. **加维**：one by one 新维 k-shot 吸收率（对应 MB 律坐席）；
5. **三年级验收**：部编版对齐的常识/数词/因果填空（有限闭集，不碰开放生成）。
及格线（候朱批）：主臂 ≥85% 且对照臂 ≤65%，差距 ≥20 个百分点。

## 预算与硬件
5090 单卡：主臂+对照臂各 ~1B token ≈ 每臂 15-20h，**一周末、¥150 内**；消融臂（去课程/去掩码/半量 token）放 Kaggle 免费夜航（双席位、日志即幸存者、torchao 疫苗照旧）。

## 输入输出契约：概念空间进，概念空间出（主人 0924 补谕，与书架案同谱）
全链路不出空间，字符串不得中途裸奔：
1. **进**：语料=概念空间的结构化供给（舱=空间、序=维度、界=给定注意力）——输入即注意力，非模型自学；
2. **题进**：探针题亦以空间形态出（带舱坐标/锚点/序位，不给孤立字符串）；
3. **空出**：答案判**落架**不判字面——模型输出词在其内部空间的舱位/锚点/序一致性=题之正确空间，即"**输出书名与输入书名在同一书架**"判据直接升为评分函数；
4. 自相似条款：这把尺先审过主人的记忆（书架案 14/14），现审模型——**审计员与考生同卷**，尺不双标即律不虚设。

## 可证伪条款（裸探针体格，三向皆可杀）
- 主臂不过 → "对齐比规模"当场塌，全族共塌照登（晨间母本判词自毁权已授）；
- 对照臂同样过 → 结构非承重，模型自学足矣——则唯一变量回到规模，园论大改；
- 双臂皆满分 → 题集太软，G3-Paper 加维重跑（题集自身之裸探针条款）。
