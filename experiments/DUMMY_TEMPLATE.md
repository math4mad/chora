# 实验结果·双版舱单 (TEMPLATE v1, 2026-09-27 主人面谕)
> 铁例：**每个 VERDICT 出生，必带 twin dummy**（袜对自反——判词与娃娃互为孪生）。
> dummy 居首（讲述位永远是小学版），专业版随后（账目给专家）。

```markdown
## VERDICT_<案名>

### 👶 dummy 版
🪜 **今天做了什么** —— 一句话，不许有术语
🎒 **打个比方** —— 生活里的事（积木/袜子/心跳/背诗/晾衣级）
🎓 **三句话带走** —— 结论、边界、下一步（每句≤20字）

### 📊 专业版
读数表（冻尺对照，逐条 ✓/✗，原始 json sha=____ 先册后读）
判词（生死条款兑现语）
连边（挂哪块 C 碑、上下游哪案）

### 🧦 袜对栏
本页 twin: 对话__ / 封条__ / 刃__ / 结果__ / 讨论__（缺者标 ⚠ 单袜）
```

## 规矩三行
1. dummy 不是删减版，是**翻译版**——比喻须与机制同构（波浪↔积木声，脑补↔袜子地图），歪了算事故；
2. 数字在 dummy 里只许一种出现法：「和…差不多/差几倍」；
3. 园笔自律：先写 dummy 再写专业版——**写不出人话的实验，说明还没懂**。
