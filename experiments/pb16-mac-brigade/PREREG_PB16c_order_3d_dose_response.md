## 0. 理论位（立梁门必答）
**本问若答『是』**：梁三加第四销——序效应在成人七域语料上复现，且集中于 **inter-schedule（域间排程）** 维，呈**粒度剂量-反应**（序越粗，波越强）。此为"序是规模饱和后最后一根不平的轴"的最强外推。
**本问若答『否』**，两种裂法分账：(a) R 臂亦起波 → 波恐非序所写、乃内容-数量差之伪影——反查 2b（其 mixed 正增量≈0 构成反证，两案必有一器有鬼）；(b) S 臂不起波 → 序效应**附条件**（幼儿低剂量/epoch 结构），梁三措辞降级候审，不豁免。

## 1. 三维分解与臂之户口
| 维 | 名 | 本案执法 |
|---|---|---|
| 一 | 内容（袋） | 三臂同一多重集（295 参训 + 100 held-out 永不参训）——冻于 MAC 册 §1，一字不改 |
| 二 | 域内序 intra | 三臂一律按 seed 洗牌——**intra 钉死为常量** |
| 三 | 域间排程 inter | **唯一变量**三档：S=整块连排（最粗）/ B=逐批七域轮转（细）/ R=全局打乱（无结构） |

底座 Qwen2.5-0.5B-Instruct 挂载 /kaggle/input/models（sha 户在册）；配方 exp11 原样 r16/α32/d0.05 七靶 lr1e-4；batch=7 · 4 epoch · **seeds {13,14,15}**（较 MAC 册 +seed15，对齐 2b 三种子判例——本案唯一剂量改动，先记）。

## 2. 观测量（本册新增）
每臂每 seed 每 epoch 于 **7 个段界各拍一次 held-out 分域 CE**（100 题卷）→ 每域 28 点轨迹 `ce_traj`；段能量/dWov/CV 照 MAC 册续记。仪器补丁先录：① k90 零能除零守卫（旧案死因）② 空段跳过 ③ 哨兵 `pb16c_ok` + REPORT_LINE 幸存者吐芯。

## 3. 判据（先冻，逐种子判，2/3 多数）
- **H-c1 不对称度**（2b 原式：正 CE 增量跨域加总 A）：**A_S ≥ 2·A_R** 且 **A_B ≤ A_S**（粒度剂量序）→ 序住于 inter；
- **H-c2 平坦对照**：|A_B − A_R| ≤ A_S/3（R、B 皆近"细/无结构"端）；
- **H-c3 节省法·成人版**：S 臂上 第4 epoch 域低点 − 第1 epoch 域低点 ≤ **−0.05 nats** 于 ≥5/7 域（阈值系 2b −0.10 向成人幅度先验折半，冻死不悔）；
- **H-c4 圈地续判**：S 臂段能量 CV ≥ 2× B 臂 CV（阶梯 vs 横纹）。
- 全过=四销同焊；任一裂法兑现按 §0 入册，**不许事后挑判据**。原始 json 先 sha 入册再判读（园律）。
