# PREREG P-B18《尾部承载假说》— 冻结于 2026-09-25（主人 C47 双锤随碑案）
> 案号避 G3 暂占之 PB17。母案: C47 分辨率即泛化律之谱定位。
> 主人命题原话 (0925, 最高证据级): 「(细节分辨的载体)不可能是大特征值的 rank-1 matrix」。

## 0. 命题与范围
- **命题**: ΔW 奇异值谱的**尾部弱方向**承载近重复对 (双胞胎级) 的分辨；头部大 σ 承载宏观共享结构。
- **几何理由** (近乎重言): 头部方向最大化跨样本共享方差, 近重复差 δ 按构造 v₁·δ≈0 → 头部对双胞胎同响应。
- **范围锁**: 只断言 LoRA ΔW 谱; 不锁全模型 (监督重赏可造"大σ配小δ"之分类头)。
- **存储/放大分离**: 尾部存差异, 状态链放大差异 (双摆逻辑) —— 小 σ ≠ 小影响。

## 0c. 坐标基旁证 (神经元消融案, 0925 验讫挂账)
- **已验**: arXiv:2308.01544《Multimodal Neurons in Pretrained Text-Only Transformers》(2023-08, 摘要原文对过)——多模态神经元把视觉表征译入残差流, 成批消融后图片描述能力系统性受损而文本能力照常——**极小元件可载关键能力**之活证 (即「存储/放大分离」中“小≠弱”一腿的坐标基版);
- **挂 † 候验**: Michaud/Liu/Gurnee/Tegmark《Understanding Digital Intelligences》系 (GPT-J 动物命名神经元消融, 能力选择性受损)——本台 arXiv 检索接口未获编号, 引用前须补验正身;
- **分账律**: 神经元案削的是**坐标系单元件**, 本案削的是**谱系频段**——两基不可互借证据; 且猫 vs 狗实为跨科粗分, 非双胞胎档——三案谱系: 神经元案证「小元件大用」(存在性), MEH 证「头段非载体」(否定面), P-B18 射「尾带定位」(肯定面+分辨力梯度)——接力不重叠。

## 1. 三臂设计 (消融靶 = 在册 adapter, PB10 验讫炮, 零新训)
| 臂 | 动作 | 预测签名 (判据先冻) |
|---|---|---|
| A 削头 | 各模块 ΔW 去掉 top-k 奇异方向 (k = 使 Frobenius 能量降 50%) | 粗分档 (人马/兄弟) NLL 崩, 双胞胎档幸存 (回 base 幅度 ≤ 噪声带) |
| B 削尾 | 去掉 bottom-k 方向 (同能量口径则单列 k' 对照) | 双胞胎档崩, 粗分档幸存 |
| C 随机 | 随机 k 方向 | 两头皆不专伤 (仪器灵敏度地板) |

- 读数 = 《双胞胎测试卡》五档 (人马→兄弟→双胞胎→拔发→换衣) 逐档 ΔNLL + 最高全对档位。
- 判据 J1: B 臂细分损伤 − B 臂粗分损伤 ≥ 2× (A 臂同差) → 假说立; 反向 ≥2× → 假说死, 照登。
- 判据 J2 (裁决器): 尾部方向**跨 seed 复现率** —— 同语料换 seed, 尾部子空间夹角 < 30° 者记信号,
  散于噪声带 (seed 散布同量级) 者记优化残余。信号率 > 50% 方许谈"承载"。
