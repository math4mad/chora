## 0. 命题

任一"无用序列"（无当前功能证据）必属两类之一，且签名可分：
- **锈刀类（retained-after-duel）**：曾参战（有父本/有同源性），胜出后闲置。
  签名 = **冻结的近期同源性**（与功能父本的分离深度有限、框与 motif 半残犹认）
  + 调控先熄（表达证据失、生化痕迹留）。
- **无源类（never-recruited）**：添入即无用（转座乘客、拼接垃圾、骨架串联体）。
  签名 = **无父本**（无同源族、无保守 motif、中性漂变速率）。

**消解之争**：ENCODE"80% 有生化活性"vs"多数真是垃圾"——两问皆错，
正问是"此序列居于生长轨迹哪一格"。

## 1. 主判据（可证伪核心）

**P-G1.1（活性富集）**：在"有生化活性证据"（DNase-HS / CAGE / H3K4me3 交集）
的无功能注释序列池内，**锈刀堆占比显著高于基线**（比值比 OR ≥ 2 才记 PASS）。
若活性均分两堆 → G1 削弱。
**P-G1.2（年轮时钟）**：锈刀堆与父本的同源分离深度分布**左偏且有界**
（近~中深度，校准于中性位点突变率）；无源堆无此结构（对任意假想父本皆无亲缘）。
**P-G1.3（位置效应）**：两源在染色体域上可分——锈刀富集于其父本所在功能域邻周
（"退役不远离驻地"），无源富集于异染色质边界/着丝粒带。

## 3. 分析步骤（冻结序）

1. 取人（hg38）+ 鼠（mm39）两系各跑一遍（跨系复现 = 格拉姆·施密特同维对表）；
2. 无功能注释序列池 → 按"有无父本"分两堆（判据：对已知功能基因族 blastn/tblastx，
   e<1e-10 且有共线块 = 有父本；另录 RefSeq locus_link 父本 GeneID 作交叉校）；
2.5 人工盲判验收：主人（或遗任熟手）以 EditSeq 只读 50 条 flatfile 盲判两源，
    与步骤 2 自动化分堆对表 —— 一致率 <80% 则先修判据再跑全量（人眼读不懂的
    签名不算签名，此为主人钦定可懂度关）；
3. 叠活性证据轨 → 2×2 列联（堆 × 有无活性）→ **P-G1.1**；
4. 锈刀堆算与父本分离深度（MegAlign 距离矩阵 / 全量用 EPO 轨）→ **P-G1.2**；
5. 坐标域分析（TSS 距离 / 着丝粒距离 / 染色体分带）→ **P-G1.3**；
6. 对照：置换检验（堆标签随机打乱 1000 次）定 p 值界。

## 4. 湿实验臂（候另批，主人的老本行）

**4a・锈刀标本库（反向遗传学 = 亲手造锈刀）**：同源重组靶向盒置换外显子 ——
基因敲除小鼠的等位基因 = **出生年月确知的锈刀**；neo/tk 筛选盒与 floxed 壳、
ER 痕迹 = **出生年月确知的无源插入**（且其失功能正是主人亲手执行的那场
受控格拉姆·施密特对决：以同源性为投影算子，把野生型那一维从结构里替换掉）。
推论两条：① 每个标准 KO 品系都是一枚**带时间戳的 G1 校准探针** ——
Southern（当年那支反向探针本身）即同源性时钟的直接测量，锈刀签名库可由
靶向盒设计反向映射基因组直接建成（把当年那张膜换成全基因组）；
② P-G1.2 的中性漂变速率校准样本现成 —— 已知建系年代品系的残余序列。

**4b・转基因沉默时间分辨**：基因枪品系思维 —— 多代继代后
甲基化敏感酶切 + Southern 拷数，直接看**锈刀生锈全过程**（调控先熄、
序列后锈 = 日期列衰减律的活体验证）。园无湿实验条件，此臂只挂账不排产。

## 6. 失败条款

- P-G1.1 不过（活性均分）→ G1 降级为"史源学趣谈"，LEDGER 记 ✗；
- 时钟分布无界 → 锈刀/无源二分失效，改连续谱表述（"年轮深浅"非"有无"）；
- 两系不复现 → 只保人系结论并标孤证。
