# PREREG E26《双端同步侦察》— 冻结于 2026-09-25 (C47 随碑案, 黑臂行为学, 零 GPU)
> 对象: 商用多端 Agent 平台 (首例: 千问 APP ↔ IDE) 的会话/概念状态同步。
> 源案: 主人 0925 手测——07:46 埋「认知探针/认知侦察兵」两枚, 「脚麻是真的」双端同现, 反推时窗 15-25 分钟。

## 1. 判据 (先冻, 两维分离——按主人"关心哪维测哪维"令)
- **D1 存在性维** (不计时): 任一时点, 在端 B 输入锚词, 响应含目标概念空间词表 (战前封存, 逐端各一张)
  = 命中; 二值, 真值只判是/否。
- **D2 时延维** (计时才约束实验): 埋针时刻 t₀ 盖戳, 端 B 首命中时刻 t₁, 重复 n≥5 记分布
  (中位数/四分位), 报典型值不报定值 (云端策略会变, 诚实条款)。
- **D3 污染哨**: 命中词表须过园子全库零命中安检 (指纹制)——防"缘分呐"类公共词假命中;
  公共语域词 (高频梗) 单列降权档。

## 2. 协议
1. 端 A 输入一组语义紧耦合但字面不重复的新造概念簇 (铸造戳在册 = 自证身份);
2. 间隔 τ 后在端 B 仅投其中一词, 记响应; 全程时间戳;
3. 对照组: 端 B 投**未埋**的同域词 (测基线命中率); 命中基线 > 20% → 词表设计失败, 重铸不重测;
4. 严禁项: 不碰账号凭据, 不自动化登录, 纯人工双端操作 + 读数入册 (行为探针本分, 黑臂不越检疫线)。

## 3. 失败与诚实条款
- 双端皆不命中 → 记「无同步」或「同步不含该层」, 二者不可区分时如实写不可区分;
- 平台官方机制说 (如"毫秒级广播") 一律 † 候证, **以探针读数为唯一证据**;
- 本案只测**平台层**状态, 不测权重——与白臂诸案 (PB10/P-B18) 分账, 禁互借证据。

## 4. 产出定位
- 园子首张「闭源平台状态同步延迟分布」观察表, 入 O-号观察账;
- 方法学意义: 探针学从"探模型"扩到"探服务"——同一根针, 扎的是不同层的皮。
